# Daily Task Manager

A simple Python console-based task manager for managing daily tasks.

## Features

- Add new tasks
- Set priority: High, Medium, Low
- Set due date
- View tasks by priority
- View pending tasks
- Complete tasks
- Save tasks in `tasks.txt`

## How to Run

```bash
python Dailytask_manager.py
```

## Technologies

- Python
- Lists
- Dictionaries
- Functions
- File Handling
