# Project Summary

## Daily Task Manager

This project is a simple Python console-based task manager.

### Main Functions

- Add tasks
- View tasks by priority
- Check pending tasks
- Complete tasks
- Save tasks in `tasks.txt`

### Technologies

- Python
- Lists
- Dictionaries
- Functions
- File Handling
